## 🚀 Featured Projects

### 🧩 LocalCodePilot
**AST-aware local code-completion engine**
- Uses Tree-Sitter AST diffing to understand structural code changes, not just token diffs
- Knapsack-based context allocator to fit the most relevant code into a limited context window
- Validated with an ablation study measuring BLEU and pass@1 on HumanEval

### 📊 FinWatch
**ML monitoring system for credit risk models**
- XGBoost model trained on 150K real credit applicants — AUC 0.8392, PR-AUC 0.3163
- Five drift detectors built from scratch: PSI, KS, ADWIN, SHAP drift, and an HMM-based regime detector
- FastAPI async backend + React dashboard, with a Gemini Flash-powered explainer layer
- Deployed on Render

### 🗄️ SQLMind
**Full-stack Text-to-SQL SaaS**
- 5-node LangGraph pipeline: Orchestrator → Schema Agent → SQL Generator → Verifier → Explainer
- pgvector-based RAG for schema grounding, plus AST-level hallucination detection via `sqlglot`
- Natural-language-to-dashboard generation
- Live: [sqlmind-app.vercel.app](https://sqlmind-app.vercel.app)

### 💰 WealthPilot (Agentic_Finance_Platform)
**Agentic finance platform, built on a Black-Litterman portfolio optimizer**
- Live: [Agentic_Finance_Platform demo](https://agentic-finance-platform-reun85wqe-aviral61.vercel.app/)
- Repo: [Agentic_Finance_Platform](https://github.com/Aviral2309/Agentic_Finance_Platform)
